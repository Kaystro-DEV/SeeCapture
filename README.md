# SeeCapture by KAYSTRO

**Smart telescope control & astrophotography for Windows**

**See. Capture. Discover.**

SeeCapture is designed to make controlling a smart telescope and capturing the night sky simple and accessible.

## Current beta

**SeeCapture Beta v0.2.2**

Currently developed for use with the **ZWO Seestar S50** on Windows.

SeeCapture is currently in beta development. Features may change and bugs may still occur. Feedback from beta testers is very welcome.

## About KAYSTRO

**KAYSTRO — Astronomy Software Made Simple**

KAYSTRO develops accessible astronomy software with a focus on simplicity and ease of use.
